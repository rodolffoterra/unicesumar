MySQL Server

É o banco de dados propriamente dito. Ele armazena as tabelas e executa os comandos SQL.

MySQL Workbench

É a interface gráfica utilizada para criar conexões, escrever consultas e administrar o servidor.

Importante: para acompanhar a disciplina no computador local, instale os dois componentes. Ter somente o Workbench não cria um banco de dados.

1. Download e instalação

1

Acesse o site oficial

Abra a página do MySQL Installer e selecione o instalador para Windows.

Abrir MySQL InstallerVer documentação oficial
2

Escolha o arquivo

Com internet durante a instalação, baixe mysql-installer-web-community (arquivo menor). Para instalar sem internet, escolha mysql-installer-community (pacote completo).

Na página de login da Oracle, você pode clicar em “No thanks, just start my download” para iniciar o download sem criar conta.
3

Execute como administrador

Abra o arquivo .msi. Se o Windows solicitar autorização, confirme. Aceite os termos apresentados pelo instalador.

4

Selecione os produtos

Use Developer Default quando estiver disponível. Essa opção inclui o MySQL Server, o MySQL Workbench e ferramentas úteis. Se utilizar Custom, confirme que estes dois itens estão selecionados:

  • MySQL Server 8.0
  • MySQL Workbench 8.0

Clique em Next e depois em Execute.

5

Configure o servidor

Mantenha as configurações recomendadas para estudo:

ConfiguraçãoValor recomendado
TipoStandalone MySQL Server
Config TypeDevelopment Computer
ConectividadeTCP/IP
Porta3306
AutenticaçãoStrong Password Encryption
6

Defina a senha do usuário root

Crie uma senha segura e anote-a em local protegido. Ela será solicitada sempre que você acessar o banco local.

Atenção: não existe uma senha padrão. Não publique sua senha em prints, códigos ou repositórios do GitHub.
7

Configure o serviço do Windows

Mantenha a opção para iniciar o MySQL como serviço do Windows e iniciar o serviço junto com o sistema. Avance até Apply Configuration, clique em Execute e finalize.

2. Criar a conexão no Workbench

1

Abra o MySQL Workbench

No menu Iniciar do Windows, procure por MySQL Workbench.

2

Localize a conexão local

Normalmente aparecerá Local instance MySQL80. Se ela não existir, clique no símbolo + ao lado de MySQL Connections.

3

Preencha os dados

CampoValor
Connection NameBanco de Dados - Aula
Hostnamelocalhost
Port3306
Usernameroot

Clique em Test Connection, informe a senha criada e confirme.

3. Validar a instalação

Abra a conexão, crie uma nova aba SQL e execute o código abaixo usando o ícone de raio.

SELECT VERSION() AS versao_mysql;
SHOW DATABASES;
Instalação concluída: se a versão do MySQL e a lista de bancos aparecerem no painel de resultados, o ambiente está pronto para as aulas.

4. Problemas comuns

Mensagem ou situaçãoComo verificar
Cannot connect to localhost:3306Abra “Serviços” no Windows, localize MySQL80 e clique em Iniciar.
Access denied for user 'root'Confirme o usuário e a senha definidos durante a configuração.
Port 3306 already in useOutro serviço está usando a porta. Configure uma porta alternativa, como 3307, e use a mesma porta no Workbench.
Workbench instalado, mas sem conexãoConfirme se o MySQL Server também foi instalado e configurado.
Pré-requisito ausenteInstale as dependências solicitadas pelo instalador e reinicie a instalação.
