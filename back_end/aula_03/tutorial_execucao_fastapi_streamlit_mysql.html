Arquitetura do projeto

Streamlit → FastAPI → MySQL → sakila.actor

A API precisa permanecer em execução enquanto o Streamlit estiver sendo utilizado.

1Abrir a pasta do projeto

Abra no VS Code a pasta raiz que contém app, streamlit_app, .env e requirements.txt.

aula_03/
├── app/
│   ├── __init__.py
│   ├── database.py
│   ├── main.py
│   └── schemas.py
├── streamlit_app/
│   └── app.py
├── .env
└── requirements.txt

2Criar a venv

python -m venv .venv

3Ativar a venv

.\.venv\Scripts\Activate.ps1
Caso o PowerShell bloqueie: 
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1

4Instalar as bibliotecas

python -m pip install --upgrade pip
python -m pip install -r requirements.txt

5Iniciar a API

No primeiro terminal:

python -m uvicorn app.main:app --reload
Não feche esse terminal enquanto estiver usando a aplicação.

6Acessar Swagger e testar o MySQL

Swagger:

http://127.0.0.1:8000/docs

Teste de conexão:

http://127.0.0.1:8000/health

MétodoEndpointFunção
GET/atoresListar atores
GET/atores/{actor_id}Consultar por ID
POST/atoresCadastrar ator
PUT/atores/{actor_id}Atualizar ator
DELETE/atores/{actor_id}Excluir ator

7Iniciar o Streamlit

Abra um segundo terminal no VS Code e ative novamente a venv:

.\.venv\Scripts\Activate.ps1

Depois execute:

python -m streamlit run streamlit_app\app.py

Acesso padrão:

http://localhost:8501

8Finalizar o Streamlit

No terminal do Streamlit:

Ctrl + C

Depois desative a venv:

deactivate

9Finalizar a API

No terminal da API:

Ctrl + C

Depois desative a venv:

deactivate
A API e o Streamlit estarão encerrados, e a venv estará desativada nos dois terminais.

Resumo rápido

Terminal 1 — API

python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload

Terminal 2 — Streamlit

.\.venv\Scripts\Activate.ps1
python -m streamlit run streamlit_app\app.py

Encerramento em cada terminal

Ctrl + C
deactivate
