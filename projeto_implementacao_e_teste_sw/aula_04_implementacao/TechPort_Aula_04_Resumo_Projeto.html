1. Resumo do que foi construído

Estruturamos a conexão Python com MySQL, protegemos a senha do banco, automatizamos a criação e a população da base TechPort e criamos interfaces em Streamlit para validar a conexão e executar consultas SQL.

.env ↓ config.py ↓ security.py ↓ connection.py ↓ MySQL ↓ techport_mysql_volumetria.sql ↓ Banco TechPort ↓ Streamlit ↓ Consultas SQL

O arquivo .env não deve ser versionado no GitHub.

4. Criptografia da senha

Utilizamos Fernet, da biblioteca cryptography, para criptografar e descriptografar a senha utilizada na conexão MySQL.

Senha original ↓ encode() ↓ Fernet.encrypt() ↓ Senha criptografada ↓ .env Na conexão: Senha criptografada ↓ Fernet.decrypt() ↓ decode() ↓ Senha original em memória ↓ mysql.connector.connect()

consultas_sql.pyLaboratório para selecionar, editar e executar SQL.

6. Primeiro teste de conexão

Antes de criar o banco, testamos a conexão com database=techport. Se o banco não existir, o MySQL retorna:

1049 (42000): Unknown database 'techport'

Esse erro é usado didaticamente para mostrar a diferença entre conectar ao servidor MySQL e conectar a um banco específico.

7. Criação e população do banco

O arquivo inicializar_banco.py conecta ao servidor MySQL sem selecionar inicialmente um database. Depois lê e executa o arquivo techport_mysql_volumetria.sql.

Arquivo SQL ↓ Path ↓ read_text() ↓ separar_comandos_sql() ↓ cursor.execute() ↓ commit() ↓ Banco TechPort criado e populado

8. Segundo teste de conexão

Depois da criação, testamos novamente a conexão com o banco TechPort e validamos:

  • Banco, versão do MySQL e usuário.
  • Estrutura das tabelas com SHOW TABLES.
  • Volumetria com COUNT(*).
  • Amostra de registros da tabela chamados.

9. Laboratório SQL

A página de consultas permite escolher uma pergunta didática, visualizar a query em um editor, modificar o SQL e executar qualquer outra consulta.

SELECT *
FROM chamados
WHERE prioridade = 'critica'
ORDER BY data_abertura DESC
LIMIT 10;

O resultado é exibido com st.dataframe().

11. Criar a .venv

Entre na pasta do projeto:

cd techport

Crie o ambiente virtual:

python -m venv .venv

12. Ativar a .venv

No PowerShell:

.\.venv\Scripts\Activate.ps1

Quando ativa, o terminal mostrará algo parecido com:

(.venv) PS C:\...\techport>

13. Instalar as dependências

python -m pip install --upgrade pip

pip install -r requirements.txt

Para conferir:

pip list

14. Abrir o aplicativo

streamlit run app/main.py

Com isso, a aplicação será aberta no navegador.

15. Encerrar a aplicação

No terminal onde o Streamlit está rodando:

CTRL + C

16. Desativar a .venv

deactivate

O prefixo (.venv) desaparecerá do terminal.

17. .gitignore recomendado

.venv/
.env
__pycache__/
*.pyc
.pytest_cache/
Assim você evita enviar ambiente virtual, segredos e arquivos temporários para o GitHub.
