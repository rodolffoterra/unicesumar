Objetivo da atividade

Nesta aula, você não construirá ainda a API. O objetivo é organizar o projeto e compreender como a arquitetura orienta a implementação.

Problema→Requisitos→Arquitetura→ C4 Model→Estrutura→Implementação→ Testes→Deploy
Importante: a estrutura criada hoje servirá de base para FastAPI, PostgreSQL, SQLAlchemy, Pydantic e Pytest nas próximas aulas.

Pré-requisitos

Python
Python 3.9 ou superior instalado.
Visual Studio Code
Editor utilizado durante a disciplina.
PowerShell
Terminal padrão do Windows.
Extensão Python
Extensão oficial da Microsoft no VS Code.
Atenção: os comandos deste tutorial foram preparados para o PowerShell/Prompt de Comando do Windows.

Comandos passo a passo

1. Preparar o ambiente

Abra o PowerShell

Utilize o terminal do Windows para executar os comandos do projeto.

Acesse a Área de Trabalho

Entre no local onde o projeto será criado.

cd "C:\Users\SEU_USUARIO\Desktop"
Alternativa

Caso o PowerShell já esteja na pasta do usuário, você pode usar:

cd Desktop

2. Criar o projeto TechPort

Criar a pasta principal

A pasta techport será a raiz do Sistema de Gestão de Chamados.

mkdir techport
Entrar no projeto

Todos os próximos comandos devem ser executados dentro dessa pasta.

cd techport
Abrir no VS Code

O ponto representa a pasta atual.

code .

3. Criar as pastas da aplicação

Código-fonte

A pasta app armazenará o código principal.

mkdir app
API

Rotas e endpoints HTTP.

mkdir app\api
Core

Configurações centrais e segurança.

mkdir app\core
Models

Entidades e modelos de persistência.

mkdir app\models
Schemas

Validação e transferência de dados.

mkdir app\schemas
Repositories

Acesso e operações com o banco de dados.

mkdir app\repositories
Services

Regras de negócio da aplicação.

mkdir app\services
Database

Configuração e conexão com o banco.

mkdir app\database
Utils

Funções auxiliares e recursos reutilizáveis.

mkdir app\utils
Tests

Testes automatizados.

mkdir tests
Docs

Documentação e diagramas do projeto.

mkdir docs

4. Criar os arquivos da arquitetura

Ponto de entrada

Arquivo principal da futura aplicação FastAPI.

type nul > app\main.py
Rotas

Arquivo inicial das rotas da API.

type nul > app\api\routes.py
Configurações

Configurações gerais do sistema.

type nul > app\core\config.py
Segurança

Autenticação, senhas, tokens e permissões.

type nul > app\core\security.py
Model de usuário

Representará os usuários.

type nul > app\models\usuario.py
Model de chamado

Representará os chamados técnicos.

type nul > app\models\chamado.py
Model de técnico

Representará os técnicos responsáveis.

type nul > app\models\tecnico.py
Schema de usuário

Validará os dados de usuários.

type nul > app\schemas\usuario.py
Schema de chamado

Validará os dados de chamados.

type nul > app\schemas\chamado.py
Repository de usuário

Operações de persistência de usuários.

type nul > app\repositories\usuario_repository.py
Repository de chamado

Operações de persistência de chamados.

type nul > app\repositories\chamado_repository.py
Service de usuário

Regras de negócio relacionadas aos usuários.

type nul > app\services\usuario_service.py
Service de chamado

Regras para abertura, atualização e encerramento.

type nul > app\services\chamado_service.py
Configuração de banco

Configuração da persistência.

type nul > app\database\database.py
Conexão

Conexão futura com PostgreSQL.

type nul > app\database\connection.py
Logger

Registro de eventos e erros.

type nul > app\utils\logger.py
README

Descrição e instruções do projeto.

type nul > README.md
Dependências

Lista de bibliotecas Python.

type nul > requirements.txt
Variáveis de ambiente

Configurações sensíveis que não devem ficar no código.

type nul > .env

tree

Exibe a estrutura completa.

tree /F
