Instalação do banco World no MySQL Workbench

Guia prático para baixar o banco de exemplo oficial do MySQL, extrair o arquivo world.sql, executá-lo no MySQL Workbench e validar a instalação.

Professor Rodolfo Terra
LinkedIn GitHub

Objetivo do laboratório

Ao final deste passo a passo, você terá o banco world disponível no MySQL e poderá começar a praticar comandos SQL utilizando as tabelas city, country e countrylanguage.

Site MySQL→ Download ZIP→ Extrair→ world.sql→ MySQL Workbench→ Executar

Passo a passo

1

Acesse a página oficial do MySQL

Abra o navegador e acesse a página de documentação e bancos de exemplo:

Abrir página oficial
Procure pela seção Example Databases.
2

Localize o World Database

Na tabela de bancos de exemplo, encontre a linha world database. Nessa linha existem opções de download.

Para este laboratório, selecione a opção Zip.
3

Baixe o arquivo ZIP

Clique em Zip e salve o arquivo em uma pasta conhecida, como Downloads ou em uma pasta da disciplina.

Exemplo de nome: world-db.zip

4

Extraia o conteúdo

No Windows:

  1. Localize o arquivo ZIP.
  2. Clique com o botão direito.
  3. Escolha Extrair tudo....
  4. Selecione a pasta de destino.
  5. Clique em Extrair.
Dentro da pasta extraída, localize o arquivo world.sql.
5

Abra o MySQL Workbench

  1. Inicie o MySQL Workbench.
  2. Abra sua conexão local.
  3. Informe a senha do usuário, caso solicitado.
  4. Aguarde o editor SQL ser carregado.
6

Abra o arquivo world.sql

No menu superior do Workbench, utilize:

File
→ Open SQL Script...
→ selecione world.sql
→ Open

O script será carregado em uma nova aba do editor SQL.

7

Execute o script

Com o arquivo aberto, clique no ícone do raio ⚡ para executar o script completo.

Aguarde o término da execução antes de fechar a aba.
8

Atualize os Schemas

No painel esquerdo do Workbench, em SCHEMAS, clique no botão de atualização.

O banco world deverá aparecer na lista.

Validação da instalação

Depois de executar o arquivo, abra uma nova aba SQL e rode:

SHOW DATABASES;

USE world;

SHOW TABLES;

Você deverá encontrar as seguintes tabelas:

TabelaConteúdo principal
cityCidades, população e país associado.
countryPaíses, continentes, população, território e indicadores.
countrylanguageIdiomas utilizados em cada país.

Primeiro teste com os dados

Execute algumas consultas simples:

USE world;

SELECT * 
FROM city
LIMIT 10;

SELECT *
FROM country
LIMIT 10;

SELECT *
FROM countrylanguage
LIMIT 10;

Consultas de conferência

Também podemos verificar a quantidade de registros:

SELECT COUNT(*) AS quantidade_cidades
FROM city;

SELECT COUNT(*) AS quantidade_paises
FROM country;

SELECT COUNT(*) AS quantidade_idiomas
FROM countrylanguage;

Checklist do aluno

  • Acessei a página oficial do MySQL.
  • Localizei a seção Example Databases.
  • Baixei o world database em formato ZIP.
  • Extraí o conteúdo do arquivo ZIP.
  • Localizei o arquivo world.sql.
  • Abri o arquivo no MySQL Workbench.
  • Executei o script completo.
  • Atualizei o painel de SCHEMAS.
  • Visualizei o banco world.
  • Consultei as tabelas city, country e countrylanguage.

Pronto para a aula

Com o banco World instalado, vamos utilizar SQL para transformar dados armazenados em informações: consultar, filtrar, ordenar, agregar e relacionar dados para responder perguntas sobre cidades, países, continentes, população e idiomas.
